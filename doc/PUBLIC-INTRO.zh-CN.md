## 一句话介绍

Agent Delivery｜灵构交付，是一个把项目、任务、人员与 AI Agent 放进同一条交付主线的 AI 原生项目交付平台。

## 简短介绍

Agent Delivery｜灵构交付面向项目负责人和交付团队，用统一工作台管理项目状态、任务执行、协作消息、资源负载与 AI Agent。它基于 Paperclip 的 Agent 控制平面能力构建，并针对中文项目交付场景重新设计信息架构与核心页面。

## 标准产品介绍

项目团队正在从单一的人力协作，转向内部成员、外部协作者与 AI Agent 共同执行。Agent Delivery｜灵构交付为这种新型团队提供统一的项目交付工作台：项目负责人可以建立项目、拆解和分配任务、查看执行状态、发现阻塞、协调资源，并在任务上下文中沉淀讨论、运行记录和交付产物。

平台保留了 Agent 注册、组织结构、心跳执行、预算控制、审批治理、活动审计、插件和外部适配器等能力，同时将产品主线收敛到公司概览、项目、任务和消息中心，让复杂的 Agent 编排以更接近真实交付管理的方式呈现。

Agent Delivery 与 Agent Work｜灵构智能属于同一产品矩阵。Agent Work 面向外部灵活用工人员的招聘与组织，Agent Delivery 面向项目执行、协作、管控与交付。两者后续计划围绕人员供给、任务执行和交付结果进行打通。

## 发布帖文案

我们正在开放 Agent Delivery｜灵构交付的早期版本。

这是一个面向项目负责人的 AI 原生项目交付与智能体协作平台。它尝试解决一个越来越实际的问题：当项目同时由内部成员、外部协作者和多个 AI Agent 参与时，怎样在同一个地方看清项目状态、分配任务、处理阻塞并保留完整的交付上下文。

当前版本已经具备公司概览、项目管理、任务管理、消息中心、Agent 管理、组织结构、执行记录、预算与审批等基础能力，支持本地自托管和二次开发。

项目仍处于公开预览阶段，我们希望优先验证真实项目中的使用方式，而不是把尚未完成的规划包装成成熟能力。欢迎体验、提出问题或参与共建。

## 面向企业的介绍

Agent Delivery｜灵构交付是一套面向企业项目团队的 AI 原生交付协作平台。平台统一承载项目、任务、人员、AI Agent、执行记录和交付上下文，帮助项目负责人识别风险与阻塞、协调资源，并在可治理的边界内引入多种 Agent 能力。

当前版本适合本地验证、内部试点和定向二次开发。企业正式部署前仍需结合现有身份体系、权限模型、数据安全、模型供应商、运维监控和备份要求完成适配与评估。

## 产品边界

当前可以对外表述：

- 已具备项目、任务、消息、Agent、组织、审批、预算和活动记录等基础能力
- 支持自托管、内嵌或外部 PostgreSQL
- 支持 Codex、Claude Code、Cursor、OpenClaw、HTTP 和外部适配器
- 已完成面向中文项目交付场景的第一阶段前端改造

当前不要表述为已完成：

- 完整的九阶段项目交付方法已经产品化
- 已与 Agent Work｜灵构智能完成系统打通
- 已具备开箱即用的企业级生产部署方案
- 已完成所有国产模型和企业系统集成
- 已通过全面的安全、性能和规模化生产验证
