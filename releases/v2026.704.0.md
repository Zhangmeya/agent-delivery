# Paperclip v2026.704.0

> Released: 2026-07-04

This stable release promotes the 2026.704 canary line after the CN fork absorbed the latest upstream environment, issue-property, dependency wakeup, and release-packaging fixes.

## Highlights

- **Custom image setup gets an in-browser terminal** - Environment custom image sessions can now expose an SSH-backed browser terminal, making image setup and debugging possible without leaving the Paperclip UI. ([paperclipai/paperclip#8911](https://github.com/paperclipai/paperclip/pull/8911), [penclipai/paperclip-cn#153](https://github.com/penclipai/paperclip-cn/pull/153))
- **Environment variable editing is richer and safer** - The new editor supports dotenv parsing, row-level source controls, secret creation/conversion flows, sensitive value handling, and refreshed tests while preserving zh-CN and en locale parity in the CN fork. ([paperclipai/paperclip#8930](https://github.com/paperclipai/paperclip/pull/8930), [penclipai/paperclip-cn#153](https://github.com/penclipai/paperclip-cn/pull/153))
- **Issue properties are easier to scan** - The issue properties pane has been split into focused components, with relation controls, external object rows, picker behavior, and CN-localized copy kept aligned with upstream behavior. ([paperclipai/paperclip#8941](https://github.com/paperclipai/paperclip/pull/8941), [penclipai/paperclip-cn#153](https://github.com/penclipai/paperclip-cn/pull/153))
- **Dependency wakeups are more reliable** - A dependency wake reconciliation backstop helps dependent issue work resume when upstream dependency state changes would otherwise leave waiting work stale. ([paperclipai/paperclip#8943](https://github.com/paperclipai/paperclip/pull/8943), @nickyleach)

## Improvements

- **CN fork sync discipline** - Core imports stay on `@penclipai/*`, zh-CN/en catalogs remain complete, Windows-oriented tests stay compatible, and upstream package updates are carried forward with the refreshed lockfile. ([penclipai/paperclip-cn#153](https://github.com/penclipai/paperclip-cn/pull/153))
- **Custom image terminal plumbing** - The release adds websocket routing, setup-session utilities, terminal session services, OpenAPI coverage, and server tests for browser terminal setup flows. ([paperclipai/paperclip#8911](https://github.com/paperclipai/paperclip/pull/8911))
- **Release packaging guardrails** - Desktop release configuration now pins the Linux executable name to the path-safe `Paperclip-CN` identity and has a regression check so future stable releases keep producing Linux AppImage assets. ([penclipai/paperclip-cn#152](https://github.com/penclipai/paperclip-cn/pull/152))

## Fixes

- **Linux desktop assets** - Stable desktop publishing no longer lets electron-builder derive an invalid executable name from the scoped package name, so Linux AppImage artifacts can be attached to GitHub Releases without manual repair. ([penclipai/paperclip-cn#152](https://github.com/penclipai/paperclip-cn/pull/152))
- **Legacy plugin migration compatibility** - The plugin entity migration now handles legacy constraint shapes during fork upgrades instead of failing on already-migrated or older local databases. ([penclipai/paperclip-cn#153](https://github.com/penclipai/paperclip-cn/pull/153))
- **Localized upstream UI changes** - New and reshaped upstream UI surfaces in environment variables, IssueProperties, and custom image setup keep translated CN fork labels, empty states, toast copy, and accessibility text.

## Upgrade Guide

- No manual breaking migration is required. Normal server startup applies the included database migration updates.
- Operators who use Linux desktop artifacts should prefer this release or newer so AppImage assets are generated with the corrected executable name.
- Operators who rely on custom environment images should expect the new browser terminal support to require the published terminal dependencies included in this release.
