# v2026.606.0

> Released: 2026-06-06

## Highlights

- **Installable team catalog** - Operators can now browse and install bundled team templates for core execution, product design, product engineering, and content operations, with catalog validation and CLI support for team workflows. ([#7550](https://github.com/paperclipai/paperclip/pull/7550))
- **Company artifacts workspace** - Companies now have a first-class artifacts area for generated deliverables, with API, UI, and work-product plumbing for inspectable outputs. ([#7621](https://github.com/paperclipai/paperclip/pull/7621))
- **Low-trust review containment** - New trust policy and source-trust plumbing helps separate low-trust inputs from governed execution paths, with red-team route coverage and operator-facing preset controls. ([#7530](https://github.com/paperclipai/paperclip/pull/7530))

## Improvements

- **Issue collaboration polish** - Issue comment tombstones, annotation-linked comments, status-change timeline text, paused-agent notices, and generated system notices now behave more consistently, including the CN fork's zh-CN localized UI paths.
- **Issue output filtering** - Document artifacts are filtered out of issue output summaries so issue pages focus on the most relevant result content. ([#7608](https://github.com/paperclipai/paperclip/pull/7608))
- **Control-plane CLI coverage** - Company and team command coverage was expanded, and the CLI docs now cover the new control-plane team flows.
- **Contributor intake and PR policy** - GitHub issue forms now collect clearer bug, feature, enhancement, and docs requests, while PR gates check linked issues and dedup-search evidence more consistently. ([#7632](https://github.com/paperclipai/paperclip/pull/7632), [#7628](https://github.com/paperclipai/paperclip/pull/7628))
- **Release and PR workflow hardening** - PR canary dry runs now consume regenerated lockfiles safely, release dry runs resolve the fork remote explicitly, and standalone bundled sandbox-provider plugins install build-time type dependencies before desktop packaging. ([#7629](https://github.com/paperclipai/paperclip/pull/7629))
- **CN fork sync readiness** - The CN fork absorbed upstream master through `a4fa0eaf5` while preserving zh-CN defaults, `penclip` command surfaces, Electron packaging behavior, external adapter boundaries, and Vitest 4 verification stability.

## Fixes

- **Deleted comment cleanup** - Deleted issue comments are redacted atomically and retain localized tombstone text instead of leaking stale body content.
- **Document and video handling** - Inline video attachment previews, document comment panel layering, and document-restore paths were tightened.
- **Routine and issue filtering** - Archived routines stay hidden, routines default by project, plan-document issue filtering is available, and stale confirmations expire after user comments.
- **Workspace runtime maintenance** - A workspace runtime kill helper and authorization coverage improve recovery for stuck local runtime sessions.

## Upgrade Guide

No manual upgrade steps are required. New database migrations for issue comment tombstones, document annotation comment links, and source trust are applied automatically.
