# v2026.602.0

> Released: 2026-06-02

## Highlights

- **Issue output playback** - Issues can now surface generated artifacts through the Output UI, including artifact metadata, attachment playback, and video issue attachments. ([#117](https://github.com/penclipai/paperclip-cn/pull/117), @penclipai)
- **Bundled skills catalog updates** - The artifact upload guidance and wireframe skill are now bundled into the skills catalog, making those workflows available without a separate manual setup step. ([#117](https://github.com/penclipai/paperclip-cn/pull/117), @penclipai)
- **Packaged desktop plugin support** - Electron packaged builds now include bundled plugin sources in the runtime so built-in plugins remain installable outside the development checkout.

## Improvements

- **PR quality and security gates** - Commitperclip review gates were added to pull requests, with fork-safe handling for repositories that cannot run GitHub Dependency Review. ([#117](https://github.com/penclipai/paperclip-cn/pull/117), [#118](https://github.com/penclipai/paperclip-cn/pull/118), @penclipai)
- **CN fork sync stability** - Windows-focused test budgets and OrgChart test setup were tightened so the upstream sync verification suite stays reliable on local Windows runners. ([#117](https://github.com/penclipai/paperclip-cn/pull/117), @penclipai)

## Fixes

- **Onboard dashboard stability** - Agent dashboard cards now keep hook order stable while run data loads and avoid nested links in the latest run card. ([#117](https://github.com/penclipai/paperclip-cn/pull/117), @penclipai)
- **Docker image publishing** - Docker builds no longer fail when there are no active dependency patch files, restoring the master container publish path. ([#118](https://github.com/penclipai/paperclip-cn/pull/118), @penclipai)
- **CN fork issue UI boundaries** - Issue output UI changes were adjusted to preserve CN fork localization, Windows, Electron, adapter, and rebrand boundaries. ([#117](https://github.com/penclipai/paperclip-cn/pull/117), @penclipai)
