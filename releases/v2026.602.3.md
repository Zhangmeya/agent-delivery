# v2026.602.3

> Released: 2026-06-02

## Highlights

- **Richer issue attachment previews** - Issue attachments now render through a dedicated preview surface with safer handling for markdown, image, and video-style attachments.
- **Standalone PWA browser controls** - Standalone and chromeless display modes now expose browser navigation controls more consistently.

## Improvements

- **Dev runner snapshot stability** - The development runner now has a shared snapshot helper and regression coverage for snapshot race behavior.
- **CN fork localization parity** - New issue attachment preview text is localized in both English and zh-CN catalogs.

## Fixes

- **Desktop bundled plugin staging** - Standalone bundled plugin installs now run outside workspace mode so package-local devDependencies are available during desktop packaging.
- **Attachment preview classification** - Preview behavior now checks attachment content type more carefully before treating filenames as markdown or video previews.
- **Standalone display-mode listeners** - PWA display-mode listener initialization is more reliable in standalone browser contexts.

## Upgrade Guide

No manual upgrade steps are required.
