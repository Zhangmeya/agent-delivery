# Paperclip v2026.714.0

> Released: 2026-07-14

This release promotes the latest Paperclip CN upstream sync and the accumulated Paperclip changes since v2026.704.0.

## Highlights

- **Cases become first-class work objects** - Experimental Cases add a structured, document-backed container for durable work beyond issues. Cases include typed fields, child cases, body documents, revision history, activity feeds, issue links, and document annotation support, giving operators a stronger place to manage release, research, and long-running coordination work.
- **Skill Studio ships as an in-app skill IDE** - Skill authors now get a three-pane editing surface, sandboxed test runs, fork prechecks, provenance, and agent-usage visibility. Built-in agents and the Reflection Coach bundle also arrive as managed resources, making reusable skills and agent packages easier to inspect and evolve.
- **Decisions and attention queue** - A new attention queue and Decisions surface collect work that needs operator action, with faster scrolling, clearer mobile action rows, and preserved custom decision labels in the Paperclip CN fork.
- **Search, filters, and command-palette parity** - Search now supports filters, sorting, operators, filter chips, recovery guidance, and command-palette alignment so large boards can be scanned and narrowed without hopping through separate pages.
- **ACP execution as the local adapter default** - Local Claude, Codex, and Gemini adapters move onto the shared ACP engine path, with sandbox execution target support, better cost propagation, external-wait liveness, and safer fallback behavior.
- **User-specific runtime secrets** - Runtime secrets can be scoped to the human responsible for a run, with definitions, per-user values, environment bindings, and pre-dispatch checks that keep governed runs from starting without the required user's secret material.
- **Work Timeline and richer execution visibility** - The Work Timeline, activity story improvements, live heartbeat progress, run ledger polish, and better timeline attribution make multi-agent work easier to scan without opening every run.
- **Paperclip CN fork sync** - The fork absorbs upstream through commit `90f85a7d1` while preserving zh-CN defaults, language switching, Windows and Electron paths, rebrand boundaries, and external-adapter discipline.

## Improvements

- **Routines can gate scheduled runs on external activity** - Scheduled routines can now wait on external activity before firing, reducing duplicate or premature automation runs.
- **Design-system convergence** - Shared UI primitives, token gates, Storybook visual baselines, bundled UI fonts, Lucide status glyphs, and a refined theme/radius ladder make the interface more consistent across dense operator surfaces.
- **Sidebar and navigation polish** - Starred resources, cleaner sidebar liveness behavior, collapsed-project indentation fixes, mobile agent-name visibility, and source-path wrapping make common navigation surfaces easier to use.
- **Workspace and recovery diagnostics** - Branch reconciliation, divergence diagnosis, break-glass recovery actions, readiness persistence, service-port validation, dirty worktree repair, and read-only diagnostics endpoints make stuck work easier to understand and recover.
- **Release and CI hardening** - Release verification is split and parallelized, stable dry-run notes are checked, general server shards are balanced by recorded duration, release package build gaps are guarded, and Storybook visual regression can run from a stable baseline.
- **Telemetry and cost accounting** - Credential health retention, telemetry proposal extraction, generated telemetry types, ACP lane usage propagation, unpriced CLI usage recording, and heartbeat cost accounting improve observability without changing operator workflows.
- **Adapter and model updates** - Codex, OpenCode, Gemini, Grok, and related local adapter defaults are refreshed, sandbox environments are enabled for Grok local, and process adapters now receive `onSpawn` for PID persistence.
- **Company skills and built-in resources** - Company skill route handling, fork prechecks, recent-skill state, built-in managed resources, and optional catalog skills continue to mature.
- **Paperclip CN localization and releaseability** - CN-specific audits kept default Chinese onboarding, language switcher behavior, action labels, token-gate compliance, Windows execution, and Electron release assets aligned with upstream.

## Fixes

- **Environment routing and custom images** - Environment editing is now a routed page with better unsaved-change handling; custom-image setup keeps company context, snapshots stay applied to tests/probes/saves, and the routed cancel test is stable in CI.
- **Workspace reliability** - Worktree activation waits for readiness, branch coherence is contained, projectless isolated worktree tasks fail fast, scratch directories are cleaned, and inherited workspace reuse is safer.
- **Heartbeat and wake stability** - Redundant issue re-wakes are throttled, plan-approval continuations survive failed wakes, dependency wake reconciliation is strengthened, and active heartbeat cleanup is less fragile.
- **Authentication and API responses** - Better Auth responses are no longer corrupted by API compression, source installs report useful unreleased SHA metadata, and run activity logs use the correct run identifier.
- **UI interaction fixes** - Experiments recovery dialogs no longer leave the UI dimmed, markdown list markers remain visible, issue threads stop jumping to the latest comment, mobile decision rows are readable, and live run text is easier to read.
- **Skill Studio and instructions editing** - Markdown dirty tracking, prose editor behavior, built-in agent asset packaging, and missing Reflection Coach asset handling are fixed.
- **Secrets and responsible-user flows** - User secret resolution, responsible-user migrations, denial outcomes, and missing-secret notices are hardened.
- **Release and packaging fixes** - Stable dry-run notes gates, runtime asset build-gap checks, release package manifest coverage, desktop release path safety, and lockfile policy behavior were tightened.
- **Paperclip CN sync follow-ups** - Onboarding language switching, decorative overlay hit targets, compact decision action labels, and the workspaces-a CI failure found during PR #156 were repaired before release.

## Upgrade Guide

- Run the normal upgrade path and let database migrations complete before starting work. This release includes migrations for Cases, Skill Studio run templates, built-in managed resources, routine activity gates, inbox dismissal snooze kind, and cost event status.
- If you operate local adapters, expect Claude, Codex, and Gemini local execution to prefer ACP-backed paths. Keep CLI credentials current and re-test any custom adapter package overrides after upgrade.
- If you use Paperclip CN desktop builds, keep the desktop data directory and CLI/server home paths separate: desktop user data remains under the `penclip` app-data slug, while CLI/server state remains under `~/.paperclip`.
- If you rely on release automation, use the GitHub stable workflow with `source_ref`, `stable_date=2026-07-14`, and a dry run before live publish.
