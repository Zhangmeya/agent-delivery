# Paperclip v2026.716.0

> Released: 2026-07-16

## Highlights

- **Governed MCP tools platform** - Connect external tool gateways, manage apps and profiles, apply company-scoped access policies, and validate integrations through the new operator UI and smoke tooling. ([#9556](https://github.com/paperclipai/paperclip/pull/9556), [#9557](https://github.com/paperclipai/paperclip/pull/9557), [#9558](https://github.com/paperclipai/paperclip/pull/9558), [#9559](https://github.com/paperclipai/paperclip/pull/9559), [#9560](https://github.com/paperclipai/paperclip/pull/9560), [#9561](https://github.com/paperclipai/paperclip/pull/9561), [#9562](https://github.com/paperclipai/paperclip/pull/9562), [#9563](https://github.com/paperclipai/paperclip/pull/9563))
- **More capable company skills** - Company skill access is open by default, skills can be imported directly from projects, and maintainers can use the active PR gardening workflow. ([#9564](https://github.com/paperclipai/paperclip/pull/9564), [#9620](https://github.com/paperclipai/paperclip/pull/9620), [#9510](https://github.com/paperclipai/paperclip/pull/9510))
- **Durable run logs** - Agent run logs can be mirrored to object storage so operators retain evidence beyond a single process lifetime. ([#8984](https://github.com/paperclipai/paperclip/pull/8984), @stubbi)

## Improvements

- **Stronger recovery and restart behavior** - Recovery now routes by failure cause, restores stranded continuations, bounds accepted-interaction continuation work, reports recovery outcomes and rate alerts, and safely adopts runs after hot restart. ([#9630](https://github.com/paperclipai/paperclip/pull/9630), [#9634](https://github.com/paperclipai/paperclip/pull/9634), [#9644](https://github.com/paperclipai/paperclip/pull/9644), [#9647](https://github.com/paperclipai/paperclip/pull/9647), [#9656](https://github.com/paperclipai/paperclip/pull/9656), [#9670](https://github.com/paperclipai/paperclip/pull/9670))
- **Faster, clearer operational UI** - Live-run updates use event-driven synchronization with bounded transcript buffers, while inbox and decision rows gain more predictable keyboard selection and expandable image galleries. ([#9569](https://github.com/paperclipai/paperclip/pull/9569), [#9624](https://github.com/paperclipai/paperclip/pull/9624), [#9627](https://github.com/paperclipai/paperclip/pull/9627), [#9532](https://github.com/paperclipai/paperclip/pull/9532), [#9680](https://github.com/paperclipai/paperclip/pull/9680))
- **Safer scheduled work** - Sub-hourly missed routine windows are coalesced into bounded catch-up runs, and repeated issue creates are deduplicated. ([#9649](https://github.com/paperclipai/paperclip/pull/9649), [#9650](https://github.com/paperclipai/paperclip/pull/9650))
- **Auditable inbox automation foundation** - Inbox archive records can retain agent and run attribution, with company-scoped per-user policies ready for future managed inbox workflows. ([#9654](https://github.com/paperclipai/paperclip/pull/9654))
- **Better search and extraction** - The search API supports bounded bulk extraction, and candidate discovery respects result limits. ([#9507](https://github.com/paperclipai/paperclip/pull/9507), [#9652](https://github.com/paperclipai/paperclip/pull/9652))
- **Safer local agent execution** - Local coding processes are confined more tightly, resolved adapter environments are forwarded consistently, and Codex authentication failures provide clearer diagnostics. ([#9504](https://github.com/paperclipai/paperclip/pull/9504), [#9617](https://github.com/paperclipai/paperclip/pull/9617), [#9259](https://github.com/paperclipai/paperclip/pull/9259), [#9276](https://github.com/paperclipai/paperclip/pull/9276), @nickyleach)

## Fixes

- **Security hardening** - Public invite tokens have more entropy and rate limits, cross-company existence checks no longer reveal protected records, and responsible-user grants are honored for company skills. ([#8979](https://github.com/paperclipai/paperclip/pull/8979), [#3967](https://github.com/paperclipai/paperclip/pull/3967), @stubbi; [#9571](https://github.com/paperclipai/paperclip/pull/9571))
- **Reliable worktree recovery** - Repair operations require target attestation and recurring workspaces avoid port conflicts. ([#9414](https://github.com/paperclipai/paperclip/pull/9414), [#9642](https://github.com/paperclipai/paperclip/pull/9642))
- **Correct interaction and profile handling** - Machine-authored comments no longer supersede decision cards, cancelled productivity reviews stop cleanly, and empty profile names are accepted safely. ([#9015](https://github.com/paperclipai/paperclip/pull/9015), @nsollazzo; [#5210](https://github.com/paperclipai/paperclip/pull/5210), @YanisThePie; [#8986](https://github.com/paperclipai/paperclip/pull/8986), @stubbi)
- **Clearer task and secret guidance** - Blocked tasks explain when a message will not reopen them, AWS secret creation failures show actionable context, and company import/export links retain the active company prefix. ([#9417](https://github.com/paperclipai/paperclip/pull/9417), [#9645](https://github.com/paperclipai/paperclip/pull/9645), [#6648](https://github.com/paperclipai/paperclip/pull/6648), @qbamca)
- **Paperclip CN release readiness** - New tools, recovery, routines, inbox, and settings surfaces remain zh-CN-first; the Windows test runner now keeps the full server suite below platform command-line limits.
