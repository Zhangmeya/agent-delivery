# v2026.605.0

> Released: 2026-06-05

## Highlights

- **Remote skill catalog references** - Optional skill catalogs can now include authenticated remote references, including the new `last30days` catalog entry, so release builds can resolve referenced skills reliably.
- **Broader API documentation coverage** - The OpenAPI surface now covers more routes and includes clearer authentication metadata for generated clients and operator integrations. ([#4579](https://github.com/paperclipai/paperclip/pull/4579), @aronprins)
- **Paused projects stay quiet** - Scheduled routine ticks are suppressed while a project is paused, reducing unexpected background work. ([#7502](https://github.com/paperclipai/paperclip/pull/7502), @dosthcpp)

## Improvements

- **Plugin and adapter reliability** - Agent JWTs can access plugin tool endpoints correctly, and plugin tool dispatch now carries `pluginDbId` so worker running-state checks resolve against the intended plugin. ([#7480](https://github.com/paperclipai/paperclip/pull/7480), @devinfoley; [#5671](https://github.com/paperclipai/paperclip/pull/5671), @Ramon-nassa)
- **CLI API parity coverage** - CLI-facing API behavior has broader regression coverage, helping command-line workflows stay aligned with the server API. ([#6626](https://github.com/paperclipai/paperclip/pull/6626), @aronprins)
- **Project and issue hygiene** - New GitHub issue forms and contributor guidance make bug, feature, and adapter requests easier to triage. ([#7575](https://github.com/paperclipai/paperclip/pull/7575), @devinfoley)
- **Release workflow hardening** - CN fork release workflows now keep npm token authentication, smoke follow-up jobs, and release verification within CI budgets so canary and stable publishing are less brittle.
- **Dependency maintenance** - Runtime, development, Docker, and GitHub Actions dependencies were refreshed.

## Fixes

- **Hermes resume-session guard** - Hermes heartbeat handling now checks resume-session state before using it, avoiding crashes when the state is absent. ([#7516](https://github.com/paperclipai/paperclip/pull/7516), @andrewylies)
- **Archived company wakeups** - Archived companies no longer wake agents, and existing archived-company agents are backfilled into a paused state.
- **Foreign tracker links** - Markdown foreign tracker keys are no longer linked as Paperclip issues in the UI. ([#7511](https://github.com/paperclipai/paperclip/pull/7511), @pmn4)
- **Issue tree persistence** - Issue anchor timestamps are coerced to `Date` before postgres binding, avoiding invalid timestamp writes. ([#5220](https://github.com/paperclipai/paperclip/pull/5220), @aperim-agent)
- **CLI and brand copy** - The CLI tagline now uses the current Paperclip positioning instead of the retired "zero-human-companies" phrasing. ([#7580](https://github.com/paperclipai/paperclip/pull/7580), @devinfoley)

## Upgrade Guide

No manual upgrade steps are required. The archived-company agent pause backfill is applied automatically by the database migration.
