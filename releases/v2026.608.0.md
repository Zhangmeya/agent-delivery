# v2026.608.0

> Released: 2026-06-08

## Highlights

- **Paperclip CN is current with upstream again** - The CN fork now includes the latest upstream instance-settings relocation, agent controls, Docker adapter updates, and wake-handoff revert while preserving CN localization, runtime language defaults, Windows compatibility, desktop release safeguards, external adapter boundaries, and `@penclipai` package scopes. ([#142](https://github.com/penclipai/paperclip-cn/pull/142))
- **Runtime default language is protected** - The runtime default language setting is wired back into wakeup context materialization, heartbeat prompt generation, adapter prompt handoff, and cross-locale coalescing safeguards, with merge-harness tests to prevent future upstream syncs from turning it into a settings-only shell. ([#142](https://github.com/penclipai/paperclip-cn/pull/142))
- **Desktop release packaging has better guardrails** - Windows desktop package size auditing now records installer size, unpacked size, file counts, and top runtime contributors so future release reviews can distinguish real regressions from expected runtime weight. ([#142](https://github.com/penclipai/paperclip-cn/pull/142))

## Improvements

- **Built-in adapters can be overridden externally** - External adapter plugins can override built-in adapter registrations, giving fork and plugin maintainers a cleaner extension path without patching core adapter imports. ([#7394](https://github.com/paperclipai/paperclip/pull/7394), @HenkDz)
- **Gemini local adapter works better in Docker** - The Docker image now bundles the Gemini CLI for `gemini_local`, reducing setup friction for container-based deployments. ([#7693](https://github.com/paperclipai/paperclip/pull/7693), @davison)
- **Instance settings live under company settings** - Instance-level settings moved into the company settings area, with CN navigation and labels kept localized after the upstream sync. ([#7680](https://github.com/paperclipai/paperclip/pull/7680), [#142](https://github.com/penclipai/paperclip-cn/pull/142))
- **Agent action surfaces are clearer** - Live-run stop finalization and clear-error actions are now available, with CN UI text added for the new clear-error controls. ([#7679](https://github.com/paperclipai/paperclip/pull/7679), [#7695](https://github.com/paperclipai/paperclip/pull/7695), [#142](https://github.com/penclipai/paperclip-cn/pull/142))

## Fixes

- **Issue comment wake handoffs returned to the last known good behavior** - The wake-handoff changes from PR #7678 were reverted after a workflow regression, while keeping narrow safeguards for accepted-plan routing, UUID skill mention filtering, and annotation wake behavior. ([#7765](https://github.com/paperclipai/paperclip/pull/7765))
- **Experimental settings are fully localized** - The Issue Plan Decomposition Panel experiment now uses stable i18n keys and zh-CN text instead of falling back to English on the CN UI. ([#142](https://github.com/penclipai/paperclip-cn/pull/142))
- **Fork sync coverage is broader** - The upstream merge harness now covers runtime localization and desktop release invariants so future syncs are more likely to catch accidental CN fork regressions before review. ([#142](https://github.com/penclipai/paperclip-cn/pull/142))

## Upgrade Guide

No manual migration is required. Existing installations can upgrade normally with `npx penclip@latest onboard` or the package manager command they already use.
