# v2026.531.0

> Released: 2026-05-31

## Highlights

- **Desktop layout stability** - The Electron app now keeps the web UI within the available desktop chrome height, preventing duplicate outer scrollbars in packaged builds. ([#111](https://github.com/penclipai/paperclip-cn/pull/111), @penclipai)
- **Embedded PostgreSQL compatibility** - Embedded PostgreSQL was updated to the upstream fixed beta, removing the local patch while preserving Paperclip's startup error handling. ([#113](https://github.com/penclipai/paperclip-cn/pull/113), @penclipai)

## Improvements

- **Desktop command coverage** - Root `desktop:*` scripts and desktop smoke commands were brought back into sync with the desktop package and documented for long-term CN fork maintenance. ([#112](https://github.com/penclipai/paperclip-cn/pull/112), @penclipai)
- **CN fork maintenance docs** - The maintenance skill and supporting docs now capture durable checks for localization, Electron packaging, OpenClaw Gateway compatibility, PR checks, and stable release verification. ([#112](https://github.com/penclipai/paperclip-cn/pull/112), @penclipai)

## Fixes

- **Chinese UI localization gaps** - Issue detail tabs, sub-issue creation, earlier comment loading, activity cost labels, skills catalog controls, and related bilingual e2e coverage were tightened for zh-CN users. ([#114](https://github.com/penclipai/paperclip-cn/pull/114), @penclipai)
- **Company-scoped settings routes** - Company export, import, org, and cloud-upstream settings links now preserve the current company prefix instead of falling back to root-level paths. ([#114](https://github.com/penclipai/paperclip-cn/pull/114), @penclipai)
